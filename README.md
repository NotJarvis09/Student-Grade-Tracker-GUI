# Student Grade Tracker GUI

A Java desktop application built with a Graphical User Interface (GUI) to manage and track student grades.

## Features
- Add and manage student names and grades.
- Calculate averages, highest, and lowest scores.
- Clean and user-friendly interface.

## Prerequisites
- Java Development Kit (JDK) installed on your system.

## Project Structure
- `Task 1/StudentGradeTrackerGUI.java`: Main source code file containing the GUI logic.

## How to Run
1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/your-repo-name.git](https://github.com/NotJarvis09/Student-Grade-Tracker-GUI.git)
   ```
2. Navigate to the project directory.
3. Compile the Java source file:
   ```bash
   javac "Task 1/StudentGradeTrackerGUI.java"
   ```
4. Run the application:
   ```bash
   java Task 1.StudentGradeTrackerGUI
   ```
